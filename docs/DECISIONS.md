# Fixed Decisions

Do not reopen these during implementation unless a measured blocker makes the current choice technically impossible.

1. Channel: Politics of Everything.
2. English-language documentaries for an international audience, with special focus on India.
3. Professional documentary-style motion graphics.
4. Runtime: 10–15 minutes.
5. Cadence: one finished documentary every Sunday.
6. Editorial identity: intellectually rigorous, accessible, non-partisan, evidence-led.
7. Scope: power, institutions, economics, society, culture, political ideas, technology and geopolitics.
8. First pilot: Who Really Controls a Democracy?
9. Foundation: fork of summitsingh/ai-video-factory under shantrath-sudo.
10. Local-first orchestration on the user's Mac; Python + launchd.
11. Reuse Remotion, FFmpeg and proven local TTS where compatible.
12. No dashboard.
13. No expensive hosted inference or paid API by default.
14. No large optional generative-video weights.
15. No unattended upload, scheduling or publication.
16. Human approval required for topic, script and final video.
17. Implementation status must be backed by code and tests.
